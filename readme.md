# EduSafe-360

**Prepare. Respond. Survive.**

EduSafe-360 is a disaster preparedness and response education platform designed for schools, colleges, and local communities. The platform aims to improve awareness, preparedness, and emergency response through real-time information, safety resources, and interactive training modules.

---

## ✨ Key Features

* Secure authentication for Students and Teachers.
* Interactive disaster information and awareness portal.
* Real-time weather monitoring using OpenWeatherMap API.
* Location-based disaster visualization using Google Maps API.
* Email notifications and disaster alerts using Nodemailer.
* Emergency contact and support directory.
* Planned support for immersive AR/VR disaster preparedness simulations.
